# homebrew-imagen

Homebrew tap for [Imagen](https://github.com/gitkeniwo/imagen), a macOS desktop app for image-to-image generation with Google's Nano Banana models via Vertex AI.

```bash
brew install --cask gitkeniwo/imagen/imagen
```

Requires macOS 15 or later on Apple Silicon. The app is ad-hoc signed and not notarized; the cask removes the download quarantine flag after install.
